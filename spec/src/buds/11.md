## Lapis implementation

The relay checks signed kind `24242` tokens on upload, mirror, get, list, and delete paths. Validation covers event ID, signature, issue and expiration times, action, optional server scope, and hash scope. The maintained adapter accepts base64url and existing padded encodings.
