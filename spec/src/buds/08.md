## Lapis implementation

Successful upload and mirror responses include `nip94` with `url`, `m`, `x`, and `size`. Image dimensions are added when the image header can be decoded. These tags describe stored bytes; application purpose and plugin declarations are separate.

| File metadata tags | The server computes descriptor tags; it does not publish a kind `1063` event for every upload. | Permitted omission | BUD-08 specifies descriptor output, not automatic event publication. | `internal/blossom/metadata.go`, `internal/blossom/server_test.go` |
