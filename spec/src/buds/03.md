## Lapis implementation

The relay accepts ordinary kind `10063` events. Community settings uploads query the active identity's events, select the latest valid signature deterministically, preserve declared server order, and fall back to the connected relay when no usable list is available. Missing-blob retrieval fallback is not yet implemented.
