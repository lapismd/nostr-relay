## Lapis implementation

`PUT /report` accepts a bounded signed kind `1984` event with at least one valid `x` hash. Reports are saved idempotently in PostgreSQL. An admin or configured manager may read the report queue through the Lapis-only `GET /api/assets/reports` endpoint using a signed BUD-11 `list` token. This endpoint defaults to 100 reports, caps `limit` at 500, and accepts a report-event ID `cursor` for newest-first pagination. It does not publish reports as Nostr events.
