## Lapis implementation

The relay exposes `PUT /mirror`, blocks private/internal network destinations after DNS resolution, bounds both request and remote response bodies, requires a successful upstream status, verifies declared and actual lengths and the authorization hash, and persists bytes atomically before returning a BUD-08 descriptor. New mirrors return `201`; existing blobs return `200`.
