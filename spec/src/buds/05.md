## Lapis implementation

`HEAD /media` checks the required hash, size, MIME, signed `media` authorization, and relay write policy. `PUT /media` verifies the request-body hash, decodes bounded static JPEG, PNG or WebP input, applies JPEG EXIF orientation, strips embedded metadata by re-encoding, preserves transparency through PNG output, and downsizes without upscaling to a 2,048-pixel maximum edge. JPEG output uses quality 85; PNG and WebP input produce lossless PNG. The BUD-08 response identifies transformed bytes and includes the original digest as `ox`. `GET /media` retains its legacy redirect to `/upload`.
