## Lapis implementation

The relay serves hash URLs; no BUD-10 relay endpoint is required. Community parses and creates canonical `blossom:` references, preserves ordered server and author hints, tries explicit servers before injected author-server discovery and configured fallbacks, bounds downloads, and verifies declared size plus SHA-256 before returning bytes.
